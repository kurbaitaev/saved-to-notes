# Build DIY PR Pipeline With AI

**Useful for:** Founders who want to earn media coverage without paying a PR agency.

## Steps
1. Scrape a list of journalists from sites where they post live story requests
2. Save the journalist list to a database — Airtable, Notion, Supabase, Postgres, or Google Sheets
3. Scrape each journalist's 10 most recent articles and store them back in the same database
4. Run a Story Ideator AI prompt (Prompt 03): feed it the journalist's request, profile, recent stories, founder dossier, and company news — outputs top 3 pitch ideas with headline, hook, and relevance score
5. Run a Pitch Writer AI prompt (Prompt 05): takes request + recent stories + founder dossier and outputs a personalized 200-word email pitch
6. Send the email; accumulate enough coverage and the Google knowledge panel appears on its own
