# 3-Layer College Essay Framework

**Useful for:** Anyone writing a Common App college essay who needs to know what to write about and how to make it stick with an admissions officer.

## Steps
1. Layer 1 — The Big Story: identify one thing that changed or is currently changing you; this is the narrative baseline, the straight line from A to B
2. Layer 2 — Key Events: add 3–5 emotionally powerful events that happened during that change to create turbulence and risk in the story
3. Layer 3 — Sensory Moments: choose 1–2 key seconds from each event and describe them using at least one sensory detail (sight, smell, sound, taste, or touch) to immerse the reader in a fully 3D experience
