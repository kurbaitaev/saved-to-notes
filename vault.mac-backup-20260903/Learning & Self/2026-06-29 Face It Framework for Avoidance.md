# Face It Framework for Avoidance

> Clarity doesn't come from thinking more. It comes from facing things.

**Useful for:** Anyone who knows what they are procrastinating on but doesn't know how to face it.

## Steps
1. Write down the one specific thing you've been avoiding — not a list, just one thing
2. Write what you think will happen if you do it — don't filter, be honest about what you're afraid of
3. Write what exactly happens if you never do it
4. Write how you would handle it if the worst case actually happened
