# Doomscrolling's Compounding Opportunity Cost

> the opportunity cost of you being addicted to doomscrolling raises every. single. second.
> — russ.lockedin

**Main thought:** Every second you spend doomscrolling, someone else is building memory techniques, persuasion skills, and high-income abilities that make them increasingly more valuable than you.
**Takeaway:** Phone addiction isn't just wasted time — it's a compounding loss as others' skills grow while yours stagnate.

## Key points
- The time spent doomscrolling is simultaneously being used by others to learn memory techniques and high-income skills
- Skills like communication, persuasion, and the ability to influence decisions compound over time into tangible value
- AI tools can replace passive phone scrolling with structured daily planning and accountability
