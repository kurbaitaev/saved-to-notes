# 3-Question Copywriting Test

**Main idea:** A three-question test to make any copy more concrete, specific, and ownable.

## Key points
- Can I visualize it? Use imagery you can picture or physically feel — e.g., 'go from the couch to running a 5K' instead of 'regain fitness'.
- Can I falsify it? Use specific, verifiable claims — e.g., 'he's 6'5", blue eyes, looks like Ryan Gosling' instead of 'he's attractive'.
- Can nobody else say it? The most powerful copy is a message only you can claim — uniqueness makes it ownable and memorable.

**Why save:** A simple, repeatable three-question framework for turning vague copy into concrete, specific, and differentiated messaging.
