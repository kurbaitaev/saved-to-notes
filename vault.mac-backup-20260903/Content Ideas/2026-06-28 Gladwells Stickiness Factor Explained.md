# Gladwell's Stickiness Factor Explained

> Once you feel something, it's a lot harder to forget.

**Main idea:** The Stickiness Factor from Gladwell's Tipping Point says a message spreads when it is built around one clear idea, packaged memorably, and designed to trigger an emotional response.
**Takeaway:** Make your message sticky and it might just hit tipping point and go crazy.

## Key points
- Have one clear idea the audience can grab onto
- Package it in a memorable way — a phrase, a visual, or a metaphor
- Create an emotional response so the message is harder to forget
