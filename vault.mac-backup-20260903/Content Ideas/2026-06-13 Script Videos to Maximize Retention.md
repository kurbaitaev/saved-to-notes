# Script Videos to Maximize Retention

Short-form tutorial by jun_yuh demonstrating a 6-step video scripting framework for retention, using the reel itself as a live example of the method.

## Summary
The creator argues that hooks alone are not enough — the algorithm rewards overall retention. They outline a 6-step scripting structure: (1) hook with a curiosity gap, (2) agitate the pain, (3) rehook with a question or scene switch, (4) establish context, (5) build toward the solution, (6) end at peak engagement to prompt a rewatch. The video itself is scripted using this exact framework as a live demonstration.

## Transcript

Everyone talks about needing a good hook, but how come when you try those viral hooks, they never seem to work? What if I told you there was something even more important? Would you believe me? Well, I just did it. Let me explain. The algorithm works based on retention. So even if your first three seconds were amazing, if the rest of the video is boring, then you'll still have a low performing video. So what you should do when you script is, number one, yes, add a hook that creates a curiosity gap. Number two, further agitate that pain so they lock in. Number three, this is really big, add a re-hook by asking a question or switching scenes. Number four, establish the context so they understand what's happening. Number five, build towards the solution. Number six, once you have them at peak engagement, end the video so you can encourage a second watch. Now watch this video back and you'll see this is exactly what I just did to you.
