# Install Addy Osmani Agent Skills

**Useful for:** Developers who want their AI coding agent to follow a structured engineering process instead of generating code chaotically

## Key points
- After installing, the agent stops writing code chaotically and follows three phases: clarify requirements → plan architecture → write code
- The skill was created by Addy Osmani, an Irish Google engineer who led Chrome DevEx and worked on Gemini developer experience

## Steps
1. Google 'Addy Osmani Agent Skills GitHub' and copy the repo link
2. Open Claude Code
3. Enter the prompt: 'I want to install Addy Osmani's skill. Research how it works and install it to improve our work' and paste the copied link
4. The agent now works in three phases: clarify what to build → create architecture and plan → write code
