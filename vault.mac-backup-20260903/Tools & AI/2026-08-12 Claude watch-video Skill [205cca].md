# Claude /watch-video Skill

**Useful for:** Anyone with a backlog of webinars, client Looms, or tutorials they want turned into structured, searchable notes automatically.

## Key points
- Transcribes the whole video
- Pulls still frames at key moments
- Writes notes on what's on screen, not just what's said
- Files everything into an organized, searchable folder
- Omit 'visual' for transcript-only mode (faster); add 'visual' to make Claude analyze frames too
- Works with YouTube, Loom, Vimeo, and local Zoom recordings
- Part of a free open-source pack of 15–19 skills by Corey Haines

## Steps
1. Add the marketplace inside Claude Code: /plugin marketplace add coreyhaines31/makerskills
2. Install the skill: /plugin install watch-video
3. Run /watch-video [video URL] — append the word 'visual' to enable frame analysis
