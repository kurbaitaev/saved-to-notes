# OpenReply Free ManyChat Alternative

> Этот 17-летний парень уничтожил главную проблему ManyChat. Он сделал его бесплатно.
> — zhilnikov_it

**Main idea:** OpenReply is a free, self-hosted open-source alternative to ManyChat that automates Instagram comment-to-DM workflows with no contact limits and no scaling costs.

## Key points
- ManyChat costs $15–$69/month and price scales with the number of contacts triggered — a viral Reel can burn a lot of money fast
- OpenReply is free to self-host; server costs ~$2/month
- Supports multiple Instagram accounts in one team dashboard with full click-level analytics (see who clicked)
- Repo includes a prompt for full AI-assisted setup via code editor (Cursor/Windsurf)
- 12 000+ GitHub stars at time of reel
