Four YouTube videos that will give you an extremely concrete basis on LLMs. If you want a visual explanation, I would go with 3 brown, 1 blue. For a more lecture-style explanation, I would go with Stanford Engineering CS classes. To see how an LLM is built out in real time, Karpathy's channel is an absolute goldmine. If you want to learn all the concepts behind LLMs but don't want to go too technical, then IBM's explanation is perfect for you.
